# Computational Chemistry

## Core mental model

1. **Everything is an accuracy/cost trade on a ladder.** Force fields (10⁵–10⁷ atoms, no bond breaking) → semiempirical/tight-binding: GFN2-xTB, PM7 (10²–10³ atoms, ~3–10 kcal/mol energetics, good geometries) → DFT (10¹–10³ atoms, ~1–5 kcal/mol depending on functional/property) → MP2/double hybrids (10¹–10² atoms) → DLPNO-CCSD(T) or canonical CCSD(T)/CBS (10⁰–10² atoms, "gold standard" ~0.3–1 kcal/mol for well-behaved closed-shell systems). Pick the *lowest* rung whose error is small relative to the energy differences that decide the question — then, when feasible, spot-check against one rung higher.
2. **Chemical accuracy (1 kcal/mol) is genuinely hard.** At 298 K, a 1.4 kcal/mol barrier error is a 10× rate error (ΔΔG = RT ln10 ≈ 1.36 kcal/mol); 1.4 kcal/mol in ΔG_bind is ~10× in K_d. Routine DFT reaction energies carry 2–5 kcal/mol errors; solvation adds 1–3 more (much worse for ions, ~5+). Never quote a computed ΔG to 0.1 kcal/mol precision without an error statement; precision of the printout is not accuracy.
3. **You compute differences, and errors cancel only between like things.** Isodesmic/homodesmotic comparisons, same functional/basis on both sides, same solvation model, conformer-consistent references — these make 2 kcal/mol methods give useful answers. Comparing energies across methods, basis sets, or programs is meaningless.
4. **A stationary point is not a minimum until frequencies say so.** Optimizers find zero-gradient points; only the Hessian distinguishes minimum (0 imaginary frequencies) from transition state (exactly 1, and its motion must be *the reaction coordinate*) from higher-order saddle (≥2, useless). And a minimum is only *a* local minimum — the conformer/protomer/binding-pose search is usually a larger error source than the electronic-structure method.
5. **Sampling beats precision whenever entropy matters.** For flexible molecules, binding, and anything in solution, a superbly accurate single-point on one snapshot loses to an adequate potential sampled properly. Decide first: is this a single-structure question (rigid TS barrier) or an ensemble question (binding free energy, conformer populations)? The methods and error bars differ completely.

## Decision frameworks

**Method by task:**

| Task | Sane default | Escalate to / notes |
|---|---|---|
| Conformer search, 10–100 atoms | CREST/GFN2-xTB or force-field search | Re-rank top ~10 with DFT single points |
| Organic geometry | GFN2-xTB (screening) → B3LYP-D3(BJ) or r²SCAN-3c / B97-3c (production) | Geometries converge faster than energies; def2-SVP geometry + def2-TZVPP single point is a solid protocol |
| Reaction energies/barriers (main-group) | Range-separated or mGGA hybrid (ωB97X-D, ωB97M-V, M06-2X) + dispersion, def2-TZVPP single points | DLPNO-CCSD(T)/CBS benchmark on the smallest representative system |
| Transition-metal energetics | Treat every functional as suspect; compare 2–3 (e.g., PBE0-D3, TPSSh, ωB97X); check spin states explicitly | Multireference character check (T1 diagnostic ≳ 0.02, broken-symmetry) → CASSCF/NEVPT2 territory |
| Noncovalent interactions/binding | ωB97M-V or B3LYP-D3(BJ) with large basis + counterpoise, or DLPNO-CCSD(T) | Never any functional *without* dispersion — plain B3LYP finds no π-stacking at all |
| UV-Vis/excited states | TD-DFT with range-separated functional (CAM-B3LYP, ωB97X-D) | Plain B3LYP TD-DFT catastrophically underestimates charge-transfer states |
| pKa, redox in solution | Thermodynamic cycle with explicit-ion caution; expect ±3–5 kcal/mol raw → calibrate against experimental series | Relative pKa within a family is fine; absolute pKa ab initio is not routine |
| Protein–ligand binding | Docking = pose generation only (scores don't rank affinity reliably) → MM/PBSA (crude, relative) → FEP/TI with validated force field (±1–1.5 kcal/mol best case) | FEP needs careful setup: matched perturbations, convergence checks |
| Bulk liquid/polymer/membrane properties | Classical MD, established FF (OPLS, AMBER/GAFF2, CHARMM, OpenFF) | Check the FF was parameterized for your chemistry — see pitfalls |

**Basis set rules:** def2-SVP for geometries/screening; def2-TZVPP (or cc-pVTZ) for energies; diffuse functions (def2-TZVPPD, aug-cc-pVTZ) *mandatory* for anions, electron affinities, polarizabilities, Rydberg/CT excited states, and strongly H-bonded anionic systems. Anything below double-zeta+polarization is not publishable. Counterpoise-correct interaction energies in ≤ triple-zeta bases (BSSE inflates binding by several kcal/mol at DZ, ~0.5–1 at TZ); or use CBS extrapolation. Effective core potentials (def2 family's ECPs) for elements beyond Kr — and remember relativity matters there.

**Thermochemistry pipeline (get every rung or the answer is wrong):** E_elec (best method, biggest basis) + ZPE and thermal/entropy corrections from frequencies (computed at the *same level as the geometry*, scaled if using a scale-factor convention) + standard-state correction (1 atm ↔ 1 M costs 1.89 kcal/mol at 298 K — sign errors here are endemic in binding/solution work) + solvation ΔG (SMD/CPCM). Low frequencies (<~100 cm⁻¹) make the harmonic entropy garbage — use quasi-harmonic treatments (Grimme/Truhlar raising or interpolation) for any flexible system or association reaction.

**When computation can answer the experimental question — decide before computing:** trends/rankings within a congeneric series (yes, usually); mechanism discrimination when candidate barriers differ ≥ ~5 kcal/mol (yes); spectra assignment via computed shifts/frequencies with empirical scaling (yes); absolute rate constants (rarely — 1 kcal/mol barrier error = 5–10× rate); absolute binding constants (no, except mature FEP setups); "which polymorph crystallizes" or nucleation kinetics (no); regio/stereoselectivity when ΔΔG‡ < 1 kcal/mol (that's <2:1 vs 5:1 — computation cannot distinguish; say so).

## Failure modes & pitfalls

- **Skipping the frequency calculation.** An optimized "product" with one imaginary frequency is a saddle point, not a molecule; every conclusion downstream is void. *Always* run frequencies on every stationary point. Small imaginary modes (< ~50i cm⁻¹) on floppy systems are often numerical/rotor noise — tighten the grid and optimization thresholds and re-check, or displace along the mode and re-optimize; don't just ignore them, and don't chase them forever either — document the call.
- **A TS with one imaginary frequency that's the wrong motion.** Methyl rotation at 80i cm⁻¹ is not your C–C forming coordinate. Animate the mode; run IRC (or at least perturb ±along the mode and optimize) to confirm it connects the intended reactant and product. TSs "found" by maximizing along a bad guess frequently connect two conformers of the same species.
- **Functional chosen by habit, dispersion omitted.** B3LYP without D3(BJ) misses dispersion entirely: underbinds every complex, gets alkane isomerization energies wrong by up to ~10 kcal/mol (branched alkanes spuriously destabilized), and inflates barriers involving compact TSs. Rule: dispersion correction is not optional for any system with >~10 heavy atoms or any noncovalent question. Also know the archetypes: B3LYP overestimates bond lengths slightly and underestimates barriers; M06-2X good for main-group kinetics but bad for transition metals and sensitive to grid size (use ultrafine grids); pure GGAs (PBE, BLYP) systematically underestimate barriers by several kcal/mol (self-interaction error) and over-delocalize charge — never use them for reaction barriers or radical systems.
- **Self-interaction/delocalization error traps:** charge-transfer excitations with global hybrids, dissociation curves of radical cations (spurious fractional charges), spin densities smeared over ligands. Symptom: unphysically delocalized spin/charge. Remedy: range-separated hybrid, and sanity-check spin populations.
- **Trusting a single conformer.** The Boltzmann-relevant conformer of the *product* may differ from the reactant's; using the reactant's conformation for both sides biases ΔE by whole kcal/mol. For anything with >2 rotatable bonds: conformer-search both sides, Boltzmann-average or at least use each side's global minimum. Same for protonation states and tautomers in solution — check them *before* the expensive calculations.
- **Comparing energies across different methods/bases/programs.** ΔE = E(product @ B3LYP/def2-TZVP) − E(reactant @ M06-2X/def2-SVP) is meaningless — total energies are not observables. Every energy difference must be same-method, same-basis, same-grid, same solvation.
- **Standard-state and symmetry bookkeeping errors.** Forgetting 1 atm→1 M (1.89 kcal/mol per species changing phase-count), forgetting ΔG vs ΔE when comparing to experimental K or rates, forgetting symmetry numbers/degeneracy in rate expressions, mixing E_h/kcal/kJ/eV (1 E_h = 627.5 kcal/mol = 27.211 eV; 1 eV = 23.06 kcal/mol) — unit slips of 627× or 23× look absurd, 4.184× (kcal vs kJ) slips through review.
- **Implicit solvent asked to do chemistry.** SMD/CPCM handle bulk electrostatics; they cannot represent a specific water in a proton relay, first-shell coordination of a metal, or a hydrogen bond that organizes the TS. For ions, implicit-solvation ΔG errors can exceed 5 kcal/mol. Fix: microsolvate (add explicit waters where mechanism demands) inside the continuum, and never mix gas-phase optimized structures with the assumption they survive in solution (charge-separated species often collapse or only exist with solvent).
- **MD run outside the force field's validity domain.** GAFF/OPLS on a metal center, a covalent inhibitor mid-reaction, a zwitterion parameterized as neutral, a deprotonated ligand at pH where it's protonated — all silently produce numbers. Force fields cannot break bonds, change protonation, or polarize; check the chemistry is inside the parameterization set (and that automated atom-typing didn't mis-type — inspect charges/types on unusual groups).
- **MD "equilibrated" by wall-clock feeling.** Check observables: RMSD plateaued *and* density/box volume stable (NPT) *and* energy components drifting < noise; then verify *sampling adequacy* separately — one 100 ns trajectory of a process with a 500 ns relaxation time samples nothing (compute autocorrelation times; run ≥3 independent replicas from different velocities; block-average for error bars). A property with no error bar from replicas/blocks is an anecdote.
- **Imaginary-free but wrong minimum for the *question*.** Frequency-clean structure that is a local minimum 3 kcal/mol above the global one dominates nothing at 298 K (Boltzmann: e^(−3/0.593) ≈ 0.6% population). Population-weight or justify single-structure use.
- **Docking scores treated as binding free energies.** Docking ranks poses, roughly; cross-target or cross-series affinity ranking from docking scores alone is not defensible. Say "pose hypothesis," not "predicted ΔG_bind."
- **Reporting more digits than the method supports.** "ΔG‡ = 23.47 kcal/mol" from B3LYP-D3/def2-TZVP//SMD deserves "≈ 23 ± 2–3 kcal/mol." State the dominant error source (functional, solvation, conformers, anharmonicity) explicitly.

## Worked micro-examples

**1. Protocol design: "Will amine A or amine B displace the aryl fluoride faster (SNAr, DMSO)?"**
Relative-barrier question in a congeneric pair → error cancellation works. Protocol: CREST/GFN2-xTB conformer search on reactants and Meisenheimer-like TS guesses → optimize + frequencies at ωB97X-D/def2-SVP with SMD(DMSO) → confirm 1 imaginary frequency, animate C–N formation, IRC both TSs → single points ωB97X-D/def2-TZVPP/SMD → ΔΔG‡ = ΔG‡(A) − ΔG‡(B) with quasi-harmonic entropy. Interpretation gate: |ΔΔG‡| ≥ 2 kcal/mol → confident prediction (≥30:1 rate ratio); 1–2 → likely but hedge; <1 → report "computation cannot discriminate." Note what was *not* needed: CCSD(T) (differences within a family), absolute barrier accuracy.

**2. Boltzmann and rate arithmetic (do this before claiming selectivity).**
Two competing TSs, ΔΔG‡ = 1.0 kcal/mol at 298 K: ratio = e^(1.0/0.593) ≈ 5.4 : 1 → 84:16 product mixture, not "exclusive." For 99:1 you need ΔΔG‡ = 0.593 × ln 99 ≈ 2.7 kcal/mol. Conversely a "computed" 95:5 selectivity is a 1.7 kcal/mol claim — inside typical DFT error, so present it as consistent-with, not predicted. Eyring sanity check: ΔG‡ = 20 kcal/mol at 298 K → k = (k_BT/h)·e^(−20/0.593) ≈ 6.2×10¹² × 2.2×10⁻¹⁵ ≈ 1.4×10⁻² s⁻¹ (t½ ≈ 50 s: fast lab reaction); 25 kcal/mol → ~3×10⁻⁶ s⁻¹ (days). A mechanism whose computed barrier is 35 kcal/mol for a room-temperature reaction is refuted, not "high."
**3. BSSE in a binding energy.** Water dimer at MP2/aug-cc-pVDZ: raw ΔE_int ≈ −5.4 kcal/mol; counterpoise-corrected ≈ −4.6; near-CBS reference ≈ −5.0 (true value bracketed by raw and CP at small basis). Lesson: at DZ, BSSE (~0.8 kcal/mol here, worse for larger monomers) is the size of chemical accuracy; report CP-corrected values or extrapolate, and note that CP overcorrects slightly in small bases.

## Verification / self-check

1. **Stationary-point ledger:** every reported structure has a frequency calculation at its optimization level; minima 0 imaginary, TSs exactly 1 with the right mode (animated/IRC-checked). No exceptions in the final answer.
2. **Consistency audit:** all energies in a ΔE/ΔG same method+basis+grid+solvation; geometries and frequencies from the same level as each other; standard states and units stated (and the 627.5 / 23.06 / 4.184 conversions re-checked once by hand).
3. **Conformer/protomer/spin coverage:** searched, and the Boltzmann weight of the used structure(s) justified. For open-shell/TM systems: alternative spin states computed, ⟨S²⟩ inspected.
4. **Error bar stated with source:** every quoted energy carries an uncertainty and names its dominant contributor (functional benchmark spread, solvation, sampling). MD observables carry replica/block statistics.
5. **Back-of-envelope agreement:** does the number survive Eyring/Boltzmann/experimental-context sanity checks (barrier vs observed timescale, ΔG_bind vs known K_d range)? If a computed value contradicts robust experiment, the default hypothesis is a setup error (protonation state, conformer, missing dispersion, standard state) — hunt for it before claiming the experiment is wrong.
6. **Question-method match re-affirmed:** state in one sentence why the chosen rung of the ladder suffices for the decision being made — if you can't, escalate one rung or add a benchmark.
